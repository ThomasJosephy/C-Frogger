# C-Frogger

A Frogger game clone written in C++ using the FLTK (Fast Light Toolkit) graphical interface library. 

## Prerequisites

To compile and run this project on Windows, you must have the following installed and configured in your system PATH:
* **GCC/G++ Compiler:** A Windows port like MinGW or MSYS2.
* **Make:** To execute the provided Makefile (often installed as `mingw32-make` or `make`).
* **FLTK Library:** The Fast Light Toolkit must be installed and accessible to your compiler.

## How to Build

1. Clone this repository and open your terminal in the project root directory.
2. Compile the project by running the `make` command:
   ```bash
   make
